# إشعار تقرير الأعمال والإنطفاء — AZL

واجهة عربية فاتحة ومتجاوبة لتسجيل المنطقة واسم العمل وفترة البداية والنهاية، مع عرض مشترك للإشعارات وتحديث مباشر عبر Supabase Realtime.

## الملفات
- `index.html`: صفحة الويب.
- `supabase-setup.sql`: إنشاء الجدول والسياسات وجدولة التصفير الأسبوعي.

## التفعيل

1. أنشئ أو اختر مشروع Supabase مستقلًا مخصصًا لـ AZL. لا تستخدم إعدادات قاعدة بيانات مشروع SLS أو أي مشروع آخر.
2. افتح **SQL Editor** في مشروع Supabase المخصص لـ AZL، والصق محتوى `supabase-setup.sql` وشغّله.
3. من إعدادات المشروع، انسخ **Project URL** و **anon/public key**.
4. افتح `index.html` وعدّل القيمتين `SUPABASE_URL` و `SUPABASE_ANON_KEY` في نهاية الملف، ثم احفظ التعديل وارفعه إلى المستودع.
5. فعّل GitHub Pages للمستودع `ops11141/azl` من **Settings → Pages** واختر الفرع الرئيسي ومجلد `/(root)` إن لم يكن مفعّلًا بالفعل.

## التصفير الأسبوعي
يُجدول SQL مهمة تمسح الإشعارات كل جمعة عند الساعة 00:00 بتوقيت السعودية (الخميس 21:00 UTC). تأكد من أن إضافة `pg_cron` مدعومة ومفعّلة في مشروع Supabase وأن المهمة تظهر في سجلات Cron. التصفير يجري من قاعدة البيانات، وليس من جهاز الزائر.

## ملاحظة وصول
الإعداد الحالي يسمح لأي زائر للصفحة بقراءة الإشعارات وإضافة إشعار دون تسجيل دخول، ولا يتيح الحذف من واجهة الصفحة. هذا مناسب لصفحة مشتركة مفتوحة، لكنه يعني أن الرابط عام ويمكن إساءة استخدامه. إذا كانت الصفحة للاستخدام الداخلي فقط، أضف تسجيل دخول أو تحققًا إضافيًا قبل نشرها للاستخدام الفعلي.

**لا تضع مفتاح `service_role` في ملف HTML أبدًا.** استخدم مفتاح `anon/public` فقط مع سياسات RLS.
